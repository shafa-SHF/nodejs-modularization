# Node.js Modularization Project

A simple Node.js project that demonstrates how to split an application into small, reusable modules.

## Project Structure
```
my-m-project/
├── modules/
│   ├── add.js
│   ├── subtract.js
│   ├── multiply.js
│   └── divide.js
├── docs/
│   └── nodejs-modularization-report.pdf
├── app.js
└── package.json
```

## How to Run
1. Clone the repo: `git clone https://github.com/shafa-SHF/my-m-project.git`
2. Go into the folder: `cd my-m-project`
3. Run: `node app.js`

## Expected Output
```
Addition: 25
Subtraction: 15
Multiplication: 100
Division: 4
```

## What I Learned
- Using `module.exports` to export functions
- Using `require()` to import modules
- Keeping code organized, reusable, and easy to maintain
